Three instruments and one murderboard.

I build small, open-source tools for measuring things in neuroscience data — and for finding out when the measurement doesn’t hold. The three instruments run in your browser, with no install and no account, and nothing you load is ever uploaded anywhere. The fourth is the review process that keeps the other three honest. Pick whichever is closest to your problem.

Calcium imaging

Colonel Kernel

Recover the shape that links action potentials to a calcium signal — from ground-truth spike times and a measured dF/F₀ trace.

Hand a trace to a tool that assumes every calcium event came from a spike and it will happily hand back a kernel, distorted by the events the spikes never caused. This one measures the relationship instead, and says so when no single shape fits.

  • convolution / deconvolution
  • teaching demonstrator
  • MIT

Endocrine time series

no_peak

CLUSTER pulse detection for hormone sampling data — LH, GnRH, GH, or any pulsatile analyte. Peak and valley tables, and a publication-grade figure.

A faithful port of Veldhuis & Johnson’s CLUSTER, validated point-by-point against both Igor Pro and the original Fortran. It also reports what CLUSTER misses, which is roughly 40% of true pulses — the page is honest about its own detector.

  • Fortran + Igor implementations
  • batch CLI
  • MIT

nopeak.tonydefazio.com→

Coordinated activity

bugarach

Find the moments when many cells fire together — and measure how often you are wrong, on a simulation built from your own recordings.

Six coordination detectors lifted out of MATLAB, scored against planted events with known times rather than against another detector’s opinion. The raster viewer draws a folder of event times in the browser with nothing installed.

  • six detectors
  • browser raster viewer
  • BSD-3

bugarach.tonydefazio.com→

Review process

The Murderboard

An adversarial review harness for document deliverables: eleven reviewer roles that try to tear a draft apart before it ships.

Every claim checked against a real source, every citation verified, every overreach attacked — plus three scripts that make “we ran all the roles” something a machine can confirm rather than something a report can merely assert. Vendored into the three projects above.

  • 11 roles
  • 3 gate scripts
  • Apache-2.0

What these have in common

A tool that flatters itself is worse than no tool.

All four grew out of the same working problem: an instrument will always return an answer, and the answer is easiest to trust exactly when nobody has checked what it cost. So each of these is built to report its own failure modes as loudly as its results — and the fourth exists to hold the other three to it.

  • Nothing uploaded No backend, no accounts, no analytics, no cookies — on all four sites. In the three instruments the algorithm is compiled into the page and runs on your own device, so a recording you analyse is never transmitted anywhere.
  • Validated, not asserted Ports are diffed point-by-point against the reference implementation they claim to reproduce, and detectors are scored against data whose ground truth is known — not against each other.
  • Open source All four repositories are public, with the caveats and the references in the repository rather than only on the page.
  • Readable without a browser Each site carries a static, JavaScript-free account of what its tool does, and each repository carries an instruction file written for an agent rather than a person.
