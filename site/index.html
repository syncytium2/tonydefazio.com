Three instruments and one murderboard.

I build small, open-source tools for measuring things in neuroscience data — and for knowing when the measurement fails. The three instruments run in your browser: no install, no account, and your data never leaves your computer. The fourth is not an instrument but a review process for any document that makes claims, tied to no field. It improves by being run against itself.

What these have in common

A tool that flatters itself is worse than no tool.

All four grew out of one problem: an instrument always returns an answer, and that answer is easiest to trust when nobody has checked what it cost. So each reports its failure modes as loudly as its results. The fourth does the same for documents.

  • Nothing uploaded No backend, no accounts, no analytics, no cookies, on all four sites. In the three instruments the algorithm ships inside the page and runs on your own device, so a recording you analyse is never transmitted.
  • Validated, not asserted Ports are diffed point-by-point against the implementation they claim to reproduce; detectors are scored against known ground truth, not against each other.
  • Open source All four repositories are public, caveats and references included.
  • Readable without a browser Each site carries a static, JavaScript-free account of what its tool does; each repository carries an instruction file written for an agent rather than a person.
