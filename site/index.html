What these have in common

A tool that flatters itself is worse than no tool.

They all grew out of one problem: an instrument always returns an answer, and that answer is easiest to trust when nobody has checked what it cost. So each reports its failure modes as loudly as its results. The murderboard does the same for documents, and the short course for the agent that helped write them.

  • Nothing uploaded No backend, no accounts, no analytics, no cookies, on every site. In the research tools the algorithm ships inside the page and runs on your own device, so a recording you analyze is never transmitted.
  • Validated, not asserted Ports are diffed point-by-point against the implementation they claim to reproduce; detectors are scored against known ground truth, not against each other.
  • Open source Every repository but ml2dl’s is public, caveats and references included; ml2dl’s is not yet.
  • Readable without a browser Each site carries a static, JavaScript-free account of what its tool does; each research-tool repository carries an instruction file written for an agent rather than a person.
